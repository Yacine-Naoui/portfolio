%-------------------- Research
\section*{Research}
\textbf{CAVIX: Early Detection and Automated Response for Multi-Stage APT Attacks} \hfill Defended Jun 2026\\
\textit{MSc thesis, pair project, graded Very Good (16.02/20). I contributed across all components.}
\begin{itemize}
  \item \textbf{Detection stack:} SecBERT embeddings of command lines, process names, file paths and URLs from Wazuh SIEM alerts, feeding an autoencoder (anomaly), a $\beta$-VAE (maliciousness), a Transformer (next Kill Chain stage) and GraphSAGE (lateral movement).
  \item \textbf{RL response agent:} designed STRIX, a Deep Q-Network that fuses the four detectors' outputs and chooses a response (monitor, alert, escalate, isolate host, block); a deterministic safety gate constrains which actions reach the network.
  \item Offset scarce labelled data with synthetic attack sequences generated by REaLTabFormer.
  \item \textbf{Results:} Linux APT Dataset 2024 (APT41, APT28, APT29, Turla; 14 weeks; 115{,}726 alerts), 2{,}000 held-out episodes: F1 0.84, 16\% false-positive rate, 81\% of campaigns stopped before Installation. Ablations: without the Transformer, pre-detection fell to 48\%; removing any single detector raised false positives to 44--52\%.
  \item \textbf{Platform and cyber range:} FastAPI backend with ARQ workers, Next.js analyst console and a React Native companion app; reproducible Docker lab driven by MITRE Caldera as the adversary, from kernel syscall to response decision in under 5~s.
  \item \textbf{Open problem:} the language model reads attacker-written strings that drive response actions, and the safety gate was never tested against an adaptive attacker.
  \item \textbf{Code:} \faGithub~\href{https://github.com/APT-Framwork/GenAI-Detection-Framework}{github.com/APT-Framwork/GenAI-Detection-Framework}
\end{itemize}
